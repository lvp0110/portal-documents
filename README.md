# Документы портала

React + TypeScript приложение: список опубликованных документов, фильтры и просмотр файлов с портала.

Файлы запрашиваются только у API портала: `/api/v2/portal` или адрес из `VITE_PORTAL_API_URL`.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

В режиме разработки Vite проксирует `/api` на `VITE_PORTAL_PROXY_TARGET` (по умолчанию `http://127.0.0.1:3005`).

Production deployment на `prodfront` описан в
[`deploy/README.md`](deploy/README.md). Публичный TLS и маршрутизацию обслуживает
отдельный `gateway-01`; приложение не публикует свой порт в интернет.

## Как пользоваться

1. Слева фильтры портала. Условия разных списков применяются вместе.
2. Выберите документ в списке. PDF открывается в карточке.
3. Скачивание забирает тот же файл с портала.
